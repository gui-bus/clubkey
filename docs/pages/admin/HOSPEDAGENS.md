# 🏨 Gestão de Hospedagens — ClubKey Admin

A tela de **Gestão de Hospedagens** (`/hospedagens`) permite aos administradores gerenciar o catálogo de vilas, chalés, resorts e hotéis boutique parceiros.

---

## 📋 Funcionalidades

1. **Catálogo de Propriedades:**
   * Visualização em grid com cards ilustrativos, avaliação média, localização e valor base da diária.
   * Status da Propriedade: `Disponível`, `Ocupada` ou `Manutenção`.

2. **Cadastro e Edição de Propriedades:**
   * Cadastro de títulos, localização, comodidades (piscina, heliponto, chef particular).
   * Definição de regras de check-in / check-out e capacidade máxima de hóspedes.
   * Tabela de tarifas dinâmicas para alta/baixa temporada e feriados.

3. **Sincronização com Motor Stays:**
   * Monitoramento das reservas sincronizadas com o PMS (Property Management System) via API Stays.
